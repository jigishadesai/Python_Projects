# Python Fundamentals – Practical Projects

A collection of three beginner-to-intermediate Python projects designed to strengthen my understanding of core Python programming concepts through practical application.

These projects focus on writing clean, reusable, and well-structured code while developing problem-solving skills and learning how to build functional applications using Python fundamentals.

## Projects Overview

### 1. Secure User Registration System

A simple user registration and authentication system that manages user accounts and validates user input.

**Features:**
- Register new users.
- Validate usernames and passwords.
- Prevent duplicate usernames.
- Authenticate existing users.
- Handle invalid inputs and registration errors.
- Display registered users.

**Key Concepts:** Functions, lists, dictionaries, loops, conditional statements, and exception handling.

---

### 2. Expense Tracker System

A simple expense management application that allows users to record, organize, and analyze their spending.

**Features:**
- Add and store expenses.
- View recorded expenses.
- Categorize expenses.
- Calculate total and average spending.
- Identify the highest expense.
- Generate spending summaries by category.
- Validate expense information.

**Key Concepts:** Functions, lists, dictionaries, loops, conditional statements, and exception handling.

---

### 3. Mini Banking System

A basic banking application that simulates essential banking operations and account management.

**Features:**
- Create bank accounts.
- Generate unique account numbers.
- Deposit money.
- Withdraw money.
- Check account balances.
- Maintain transaction histories.
- Display account summaries.
- Prevent withdrawals exceeding available balances.
- Validate transactions and handle errors.

**Key Concepts:** Functions, lists, dictionaries, loops, conditional statements, and exception handling.
